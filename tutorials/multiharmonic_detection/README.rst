Multi-Harmonic Detection
========================

Multi-harmonic detection (MHD) reconstructs the minimally-broadened 1st-derivative CW EPR lineshape from several harmonics of a strongly over-modulated field-modulated signal, recovering signal-to-noise that over-modulation would otherwise trade away for resolution. This series covers the theory, a fully synthetic worked example, analysis of real experimental data, and how to tune the reconstruction's filter parameters.
